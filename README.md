In these exercises I explore the basic SQL Fundamentals for Beginners

I answer different questions based on the Employees table given

The goal is to Retrieve data with SELECT — both all columns (SELECT *) and specific columns.

Remove duplicate values from results with DISTINCT.

Sort results using ORDER BY (ascending and descending).

Limit the number of rows returned with LIMIT.

Filter rows with WHERE, combining conditions using AND, OR, NOT, and IN.

After filtering each question, I then supplied the results tables as it would run on SQL.
